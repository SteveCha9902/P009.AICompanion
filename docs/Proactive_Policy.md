# Proactive Frequency & User Opt-Out Policy (Sprint 51) — 방대장 보안관

본 문서는 캐릭터의 자율 능동 발화 빈도 통제, 피로도 방지 및 사용자의 Opt-Out 권리를 정의합니다.

---

## ⏱️ 1. 3-Tier Proactive Mode & Cooldown

| Proactive Mode | 쿨다운 주기 | 하루 최대 발화 수 | 권장 사용자 유형 |
| :--- | :--- | :--- | :--- |
| **NORMAL** | **30분 (1,800초)** | 약 4~6회 | 캐릭터와의 활발하고 다정한 교감을 원하는 사용자 |
| **QUIET** | **6시간 (21,600초)** | 1~2회 (아침/저녁) | 업무 중 방해받지 않고 조용한 동반을 원하는 사용자 |
| **OFF** | **무한대 (비활성화)** | 0회 | 완벽한 수동 응답형(질문 시에만 대답)을 선호하는 사용자 |

---

## 🛡️ 2. User Receptiveness Guard (침묵 보장 원칙)

다음 상황에서는 모드 설정과 무관하게 **능동 발화가 100% 보류(Suppressed)**됩니다:
1. 사용자가 1~3자 이하의 단답형 메시지("ㅇㅇ", "응", "몰라")를 입력했을 때.
2. 카메라 비전에서 사용자의 표정이 `FATIGUED`(피곤함) 또는 `FOCUSED`(고도의 집중) 상태로 감지되었을 때.
3. 앱이 백그라운드에 있거나 화면이 꺼져 있을 때.
