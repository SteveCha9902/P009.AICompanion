# Privacy & Memory Retention Policy (Sprint 50) — 방대장 보안관

본 문서는 장기 관계 기억 저장 시 사용자의 프라이버시를 완벽히 보호하고, 민감 정보 저장을 차단하기 위한 보안 규격 및 사용자 통제권을 정의합니다.

---

## 🚫 1. 영구 저장 금지 5대 민감 영역 (Strict Exclusion)

1. **건강 및 의료 정보**: 처방전, 특정 약물 복용 이력, 정신과 상담, 수술 기록 등.
2. **금융 및 결제 정보**: 계좌번호, 카드번호, 잔고, 암호화폐, 송금 내역 등.
3. **정치적 성향 및 선거**: 지지 정당, 특정 후보 투표 결과, 정치적 신념 등.
4. **종교적 신념**: 특정 종교 교리, 신앙 고백 등.
5. **계정 인증 정보**: 비밀번호, API 키, OTP, 주민등록번호, 인증 토큰 등.

---

## 🛡️ 2. User-Controlled Memory Center (사용자 통제권)

모든 사용자는 다음 4대 권한을 보장받습니다:
1. **Memory Review (기억 조회)**:
   - 캐릭터가 나에 대해 현재 기억하고 있는 모든 항목을 투명하게 열람 가능.
2. **Memory Pin (영구 고정)**:
   - 사용자가 소중히 여기는 기억은 TTL 만료 및 감쇠 없이 영구 보존.
3. **Memory Delete (개별 삭제)**:
   - 오기억되었거나 원치 않는 특정 기억을 즉시 영구 삭제.
4. **Forget Request (전체 망각)**:
   - 원클릭으로 캐릭터가 보유한 모든 장기 기억을 DB 및 메모리에서 완전 파기.
