# P009 AI Companion - Mobile Testing Guide

이 문서는 P009 AI Companion 시스템을 실제 모바일 기기(Android)에서 테스트하기 위한 가이드입니다.

## 1. 테스트 준비 (사전 요구사항)

모바일 기기에서 AI Companion과 통신하려면, **반드시 백엔드 서버가 먼저 실행되어 있어야 합니다.**

1. 터미널을 열고 백엔드 디렉터리로 이동합니다.
   ```bash
   cd d:\99.Repos\00.AntiGGG\P009.AICompanion\backend
   ```
2. FastAPI 백엔드를 실행합니다. (모바일에서 접근할 수 있도록 `0.0.0.0`으로 엽니다)
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
3. 현재 PC의 로컬 IP 주소(예: `192.168.x.x`)를 메모해 둡니다. 모바일 앱이 이 주소를 통해 백엔드와 통신하게 됩니다.

---

## 2. 테스트 방법 선택

P009를 모바일에서 테스트하는 방법은 두 가지가 있습니다. 상황에 맞게 선택하세요.

### 방법 A: Expo Go 앱으로 즉시 테스트 (가장 권장)
코드 수정 결과를 실시간으로 확인하고 싶을 때 사용합니다. 빌드 대기 시간이 없습니다.

1. Android 스마트폰의 Google Play 스토어에서 **Expo Go** 앱을 설치합니다.
2. 새 터미널을 열고 모바일 디렉터리로 이동합니다.
   ```bash
   cd d:\99.Repos\00.AntiGGG\P009.AICompanion\mobile
   ```
3. Expo 개발 서버를 시작합니다.
   ```bash
   npx expo start
   ```
4. 터미널에 나타난 **QR 코드**를 스마트폰의 카메라 앱이나 Expo Go 앱으로 스캔합니다.
5. P009 앱이 스마트폰에서 즉시 실행됩니다.

### 방법 B: 단독 APK 앱으로 설치하여 테스트
완전한 앱 형태로 스마트폰에 설치해두고 일상생활 속에서 백그라운드 테스트 등을 진행하고 싶을 때 사용합니다.

1. 모바일 디렉터리에서 아래 명령어로 빌드를 시작합니다. (Expo 계정 로그인 필요)
   ```bash
   cd d:\99.Repos\00.AntiGGG\P009.AICompanion\mobile
   eas build -p android --profile preview
   ```
2. 약 10~15분 정도 대기하면, 터미널에 **APK 파일을 다운로드할 수 있는 웹 링크(URL)**가 출력됩니다.
3. 해당 링크를 스마트폰의 인터넷 브라우저에 입력하여 `.apk` 파일을 다운로드합니다.
4. 스마트폰 설정에서 "출처를 알 수 없는 앱 설치"를 허용하고, 다운로드된 파일을 실행하여 앱을 설치합니다.

## 3. 핵심 E2E 검증 시나리오 (Sprint 15 체크리스트)

테스트를 진행하실 때 아래의 5가지 시나리오가 정상 동작하는지 확인해 보세요.

- [ ] **Memory Continuity**: 앱에서 음성이나 텍스트로 내 취향이나 정보를 말한 뒤 앱을 종료하고 다시 켰을 때, 지니(Companion)가 이를 기억하고 대화에 반영하는가?
- [ ] **Voice Interrupt**: 지니가 음성으로 대답하고(Speaking) 있을 때 마이크 버튼을 누르면, 지니의 말이 즉시 끊기고 내 말을 듣는(Listening) 상태로 전환되는가?
- [ ] **Privacy Boundary (Background)**: 스마트폰 홈 화면으로 나가서 앱이 백그라운드로 전환되었을 때, 카메라와 마이크 권한이 확실하게 해제되는가?
- [ ] **Vision to Emotion**: 카메라를 활성화하고 내가 화면을 보고 웃었을 때, 지니가 이를 인지하고(Observation) 반응이 긍정적으로 변화하는가?
- [ ] **Failure Isolation**: 텍스트 채팅 중 카메라 접근 권한을 임의로 차단했을 때, 앱이 크래시되지 않고 텍스트 대화는 정상적으로 계속 작동하는가?

> **문제 발생 시**: 모바일 앱에서 백엔드로 연결되지 않는다면, PC의 방화벽 설정이나 모바일 앱 코드 내 백엔드 API 주소(`http://localhost:8000` 가 아닌 `http://192.168.x.x:8000`)를 확인하세요.
