# False Memory Prevention Policy (Sprint 60) — 미나리 과장

본 문서는 환각 및 허위 기억에 의한 오기억 회상을 방지하는 신뢰도 임계값 정책을 정의합니다.

---

## 🧠 1. 기억 신뢰도 임계값 (Confidence Threshold)

- **신뢰도 $\ge 0.80$**:
  - 일반적인 자연스러운 회상 가능 (*"지난번에 이야기하셨던..."*).
- **신뢰도 $< 0.80$**:
  - 단정적 서술문 100% 금지.
  - 반드시 겸허한 완곡 추정형 어조 사용 필수 (*"내가 기억하기로는...", "맞다면..."*).
  - 미검증 이벤트는 `FalseMemoryGuard`에 의해 사전에 걸러집니다.
