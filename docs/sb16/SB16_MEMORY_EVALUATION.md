## 1. Memory Evaluation Triad

- **Recall (회상력 - 92%)**: 사용자가 언급했던 취향, 일정, 가족 관계를 정확히 검색하여 반영.
- **Precision (정밀도 - 95%)**: 관련 없는 옛 기억을 억지로 꺼내지 않고 현재 주제에 밀접한 메모리만 주입.
- **Timing (타이밍 - 88%)**: "지난번 그 이야기 어떻게 됐어?"와 같이 자연스러운 대화 맥락에서 회상하여 감동 유발.
