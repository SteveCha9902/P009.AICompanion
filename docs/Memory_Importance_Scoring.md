# Memory Importance Scoring Guide (Sprint 50)

본 문서는 사용자의 발화로부터 기억 후보를 추출하고, 3축 평가 매트릭스를 통해 장기 기억으로 영속할지를 판별하는 채점 기준을 정의합니다.

---

## 📊 1. 3축 평가 매트릭스 (3-Axis Scoring Matrix)

```text
Final Composite Score = Importance (0.0~1.0) × Future Relevance (0.0~1.0) × Relationship Value (0.0~1.0)
```

1. **Importance (핵심 삶의 중요도)**:
   - 사용자의 인생, 건강, 가족, 반려견, 진로 등에 얼마나 핵심적인가?
2. **Future Relevance (미래 연관성 / 지속성)**:
   - 다음 주, 다음 달, 다음 계절에도 의미가 유지되는가?
3. **Relationship Value (관계 형성 가치)**:
   - 캐릭터와 사용자 간의 정서적 유대와 공감을 깊게 만드는가?
