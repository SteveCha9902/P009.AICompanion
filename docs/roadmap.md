# Development Roadmap

P009.AICompanion의 Sprint 기반 장기 개발 로드맵입니다.

- **Sprint 0**: Foundation Architecture (설계, 문서화, 도메인/인프라 셋업) <- 현재 진행 단계
- **Sprint 1**: Mobile Shell + Basic Conversation (React Native 채팅 프레임 및 서버 연동)
- **Sprint 2**: Persona Engine (데이터 기반 성격 부여)
- **Sprint 3**: Memory Engine (장기 기억 추출 및 검색)
- **Sprint 4**: Emotion Engine (감정 상태 전이)
- **Sprint 5**: Relationship Engine (유대 관계 및 친밀도 모델링)
- **Sprint 6**: Companion State + Behavior Engine (행동 결정 파이프라인)
- **🎯 MVP-1 Milestone**: 모바일 환경에서 텍스트 기반으로 기억, 감정, 관계를 갖춘 Companion 시연
- **Sprint 7**: Voice (STT/TTS 통합)
- **Sprint 8**: Camera + Vision (모바일 카메라 기반 Edge Vision 파이프라인)
- **Sprint 9**: Gaze + Avatar Interaction (시선 추적 및 아바타 애니메이션 연동)
- **🎯 MVP-2 Milestone**: 시각/청각을 통해 교감하는 인터랙티브 아바타
- **Sprint 10**: Ambient Companion (Push Notification, Background Event 연동)
- **Sprint 11**: Autonomous Behavior (완전 자율 행동 로직 고도화)
- **🎯 MVP-3 Milestone**: 앱을 열지 않아도 항상 함께 존재하는 완벽한 AI Companion
